# إصلاح COGS — عدم تطابق مفاتيح JSON (3 يونيو 2026)

## المشكلة
صفحة `accounting/reports` كانت تعرض: الإيراد = الربح الإجمالي = صافي الربح = 9,569.70، وهامش 100% — أي COGS = صفر.

## الجذر الحقيقي
الدوال المحاسبية كانت تقرأ مفاتيح غير موجودة في `orders.items`:
- `item->>'slug'` ← الصحيح `product_slug`
- `item->>'quantity'` ← الصحيح `qty`
- `item->>'price'` ← الصحيح `unit_price`
- `WHERE item ? 'slug'` كان يستبعد **كل** العناصر (لا عنصر يملك مفتاح `slug`).

النتيجة: `get_product_cost_at(NULL, ...)` → NULL → `COALESCE(...,0)` → COGS = 0 دائماً.

> ملاحظة: إصلاح `effective_from = 26 مايو` السابق كان صحيحاً لكنه عديم الأثر لأن الدوال لم تكن تعثر أصلاً على الـslug.

## الفحص (PHASE 1)

**التسليم التلقائي غير متأثّر إطلاقاً.**

## الإصلاح (PHASE 2)
